# Fonts

All fonts are licensed under the SIL Open Font License 1.1 (free to use and bundle). License texts sit next to this file as `OFL-<font>.txt`.

| Font | Role (Nothing skin) | Source |
|---|---|---|
| Doto (variable, ROND + wght) | Display, only at 20sp/px and above | https://github.com/google/fonts/tree/main/ofl/doto (`Doto[ROND,wght].ttf`) |
| Space Mono (Regular, Bold) | Labels, headings, numbers | https://github.com/google/fonts/tree/main/ofl/spacemono |
| Inter (variable, opsz + wght) | Body | https://github.com/google/fonts/tree/main/ofl/inter (`Inter[opsz,wght].ttf`) |

Doto is a placeholder for our own dot-matrix font. Inspired by the dot-matrix aesthetic of Nothing's design language; not affiliated.

Android copies live in `android/app/src/main/res/font/` (`doto.ttf`, `space_mono_regular.ttf`, `space_mono_bold.ttf`, `inter.ttf`).
