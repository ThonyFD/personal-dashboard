# Brand Book

Manual de marca basado en [logo-prismatic-green.svg](./logo-prismatic-green.svg).

## 1. Introduccion de la marca

La identidad visual proyecta una marca tecnologica, ambiciosa y orientada a resultados. El simbolo combina una estetica futurista con un mensaje funcional: impulsar, sostener y senalar crecimiento o accion relevante.

Nota de produccion: aunque el archivo fuente esta en formato SVG, gran parte de su acabado visual depende de imagenes raster embebidas y recortadas dentro del simbolo. Esto condiciona la escalabilidad extrema, la impresion y la creacion de variantes monocromaticas.

## 2. Concepto del logo

El logo comunica progreso guiado. La mano representa soporte, control y acompanamiento; la flecha ascendente expresa crecimiento, mejora o rendimiento; el signo de exclamacion aporta urgencia, insight o foco.

El acabado prismatico y luminoso refuerza una percepcion de innovacion, velocidad, lectura de senales y vision de futuro.

### Tipografia inferida

El SVG no contiene texto editable ni una tipografia embebida. Por estilo, el sistema visual es compatible con familias geometricas, tecnologicas y limpias, con muy buena legibilidad en entornos digitales.

### Formas, simbolos y composicion

- Mano abierta: soporte, guia, control, servicio, inteligencia aplicada.
- Flecha ascendente: crecimiento, progreso, performance, optimizacion.
- Signo de exclamacion: alerta, accion, descubrimiento, foco estrategico.
- Contenedor cuadrado con esquinas redondeadas: lectura inmediata de icono digital o app icon.
- Fondo oscuro con particulas y facetas: profundidad, entorno tecnologico, sensacion de sistema avanzado.

- La marca funciona mejor sobre fondos oscuros, especialmente `#081022`.

## 6. Tipografia recomendada

Estas recomendaciones son inferencias estilisticas compatibles con el logo.

| Sistema | Fuente recomendada | Uso |
| --- | --- | --- |
| Tipografia principal | `Space Grotesk` | Titulares, claims, headers de producto |
| Tipografia secundaria | `Manrope` | Cuerpo de texto, UI, dashboard, email |
| Alternativa expresiva | `Sora` | Portadas, piezas hero, presentaciones |
| Alternativa tecnica | `IBM Plex Sans` | Documentacion, tablas, interfaces densas |

### Recomendacion de jerarquia

- Titulos: `Space Grotesk` SemiBold o Bold
- Subtitulos: `Space Grotesk` Medium
- Cuerpo: `Manrope` Regular o Medium
- Botones: `Manrope` SemiBold
- Dashboards densos: `IBM Plex Sans`

## 7. Versiones del logo

### Version principal

Isotipo completo dentro de contenedor cuadrado redondeado con fondo oscuro.

### Version horizontal

Isotipo a la izquierda y wordmark a la derecha. Requiere construir un wordmark, ya que el SVG actual no lo incluye.

### Version vertical

Isotipo arriba y wordmark debajo. Tambien requiere wordmark adicional.

### Version monocromatica

Version a una tinta, sin brillos, texturas ni efectos glass.

### Version en negativo

Version blanca o cian muy claro sobre fondo oscuro solido.

### Isotipo

Usar mano + flecha + exclamacion, idealmente con menos particulas para aplicaciones funcionales.

### Fondos claros y oscuros

- Fondos oscuros: entorno natural del logo.
- Fondos claros: usar una adaptacion con contenedor oscuro o version simplificada de alto contraste.

## 8. Area de seguridad

Definir `x` como el grosor del cuerpo vertical del signo de exclamacion.

- Margen minimo alrededor del logo completo: `1x`
- Margen ideal para piezas de marca o hero: `1.5x`

## 9. Tamanos minimos

| Uso | Tamano minimo recomendado |
| --- | --- |
| Web detallado | `96 px` |
| UI secundaria | `64 px` |
| Redes sociales | `320 px` a `512 px` |
| Impresion | `25 mm` minimo, `35 mm` recomendado |
| Favicon / app icon | Crear variante simplificada para `48 px`, `32 px` y `16 px` |

## 10. Usos correctos

- Aplicarlo sobre fondos oscuros lisos o degradados suaves.
- Usarlo en contextos digitales de producto, dashboard, app o presentacion.
- Mantener buen contraste y suficiente aire visual.
- Emplear la version detallada solo en tamanos medianos o grandes.
- Conservar proporciones, colores y jerarquia de brillos.

## 11. Usos incorrectos

- Deformar o estirar el logo.
- Cambiar los colores base por variantes ajenas al sistema.
- Colocarlo sobre fondos claros sin adaptacion.
- Agregar sombras duras, bevels o efectos externos no definidos.
- Rotarlo.
- Alterar proporciones o composicion del simbolo.
- Reemplazar el sistema tipografico sugerido por uno decorativo no compatible.
- Reducirlo demasiado manteniendo todos los detalles.

## 15. Guia rapida de implementacion

- Usar fondo oscuro como contexto principal.
- Mantener `#00D9FF` como color central del sistema.
- Reservar `#39FF14` para accion y estados positivos.
- Limitar `#7A5CFF` a acentos.
- No usar la version detallada en microescala.
- Crear y usar una version simplificada para favicon e impresion.
- No tratar este SVG como master final de produccion.

## 16. Recomendaciones finales

- Redibujar un master 100% vectorial para produccion.
- Crear una familia oficial: hero, flat, monocroma, negativa y micro-icon.
- Desarrollar un wordmark si la marca necesita expresion corporativa completa.
- Definir equivalentes CMYK o Pantone si habra uso impreso.
- Simplificar particulas y reflejos para mejorar consistencia, escalabilidad y performance visual.

## 17. Instrucciones para LLMs y desarrollos visuales

Cuando un LLM genere interfaces, componentes, landings, presentaciones o piezas de producto para este repositorio, debe asumir este documento como fuente de verdad visual.

### Reglas operativas

- Preservar la direccion visual futurista, tecnologica y orientada a growth.
- Evitar layouts genericos de SaaS blanco con acento morado por defecto.
- Priorizar fondos oscuros profundos con acentos `#00D9FF` y `#39FF14`.
- Usar tipografia de estilo geometrico y contemporaneo, preferentemente `Space Grotesk` y `Manrope` o alternativas equivalentes.
- Mantener una estetica intencional, nitida y de alto contraste.
- Si una pieza necesita simplificacion tecnica, simplificar detalles antes de alterar el concepto visual.
