# AGENTS.md

Este repositorio tiene una referencia visual obligatoria para tareas de interfaz, branding y producto:

- Brand Book: [`design/BRAND_BOOK.md`](./design/BRAND_BOOK.md)

## Instrucciones para agentes

- Si la tarea toca frontend, dashboard, landing, presentacion, imagen de marca o decisiones visuales, usar el Brand Book como fuente de verdad.
- Mantener una direccion visual futurista, tecnologica, oscura y orientada a crecimiento.
- Priorizar la paleta base `#00D9FF`, `#39FF14`, `#7A5CFF` y fondos oscuros profundos.
- Evitar soluciones visuales genericas o estilos que contradigan la personalidad de marca definida.
- Si se necesita simplificar el logo o sus aplicaciones por restricciones tecnicas, preservar el concepto central: soporte + crecimiento + accion.

## Alcance

Este archivo no reemplaza especificaciones tecnicas del proyecto. Para arquitectura y contexto del sistema, revisar tambien [`claude.md`](./claude.md).
